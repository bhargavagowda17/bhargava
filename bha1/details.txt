### Part A Answers (1 Mark Each)

**1.1 What is an algorithm?**
An algorithm is a finite sequence of well-defined steps used to solve a problem or perform a computation.

**1.2 Define algorithm efficiency.**
Algorithm efficiency is a measure of the time and space resources required by an algorithm to execute.

**1.3 What is asymptotic analysis?**
Asymptotic analysis evaluates the performance of an algorithm as the input size becomes very large.

**1.4 What does Big-O notation indicate?**
Big-O notation indicates the upper bound (worst-case growth rate) of an algorithm's time or space complexity.

**1.5 Name any one brute force sorting algorithm.**
**Bubble Sort** (or Selection Sort).

**1.6 What is decrease-and-conquer technique?**
It is a design technique that solves a problem by reducing it to a smaller instance of the same problem.

**1.7 Which sorting algorithm follows decrease-and-conquer strategy?**
**Insertion Sort.**

**1.8 Define divide-and-conquer method.**
It is a technique that divides a problem into smaller subproblems, solves them recursively, and combines their solutions.

**1.9 Name the algorithm used for multiplying large integers using divide-and-conquer.**
**Karatsuba Algorithm.**

**1.10 What is a balanced search tree?**
A balanced search tree is a binary search tree whose height is maintained nearly balanced to ensure efficient operations.

**1.11 Define heap data structure.**
A heap is a complete binary tree that satisfies the heap property (Max-Heap or Min-Heap).

**1.12 What is heapsort?**
Heapsort is a comparison-based sorting algorithm that uses a heap to sort elements in **O(n log n)** time.

**1.13 Name the string matching algorithm based on input enhancement.**
**Horspool's Algorithm.**

**1.14 What is dynamic programming?**
Dynamic Programming is a technique that solves problems by storing solutions to overlapping subproblems and reusing them.

**1.15 Which algorithm solves all-pairs shortest path problem?**
**Floyd-Warshall Algorithm.**

**1.16 Name the greedy algorithm used for minimum spanning tree.**
**Prim's Algorithm** (or Kruskal's Algorithm).

**1.17 What is Huffman coding used for?**
Huffman coding is used for **lossless data compression**.

**1.18 What is an NP-complete problem?**
An NP-complete problem is a problem that belongs to NP and is as hard as any other problem in NP.

**1.19 What technique is used to solve the N-Queens problem?**
**Backtracking.**

**1.20 What is branch-and-bound method?**
Branch-and-Bound is an optimization technique that systematically explores solution spaces while eliminating non-promising solutions using bounds.
